## Зроблено
### web/ (новий застосунок)
- Конфіги (Next 15, TS, `:3001`), `lib/api.ts` (auth/events/tickets/reviews/organizer + helpers maps/date/price),
  `globals.css` (публічний темний сайт), `TopNav` (Афіша / Мої квитки / Кабінет / Увійти-Вийти).
- `/` — **афіша**: пошук + чипи категорій + «Безкоштовні», грід карток (no-auth).
- `/events/[id]` — **деталі**: постер/галерея/відео/соцлінки, **адреса→Google Maps**, ціна/лишилось,
  **купити-квиток** (free→reserve; paid→checkout+pay-test, login-gate з `?next=`), **відгуки** (рейтинг після старту).
- `/login`, `/register` — auth (токен у localStorage `ug_web_token`).
- `/me/tickets` — **квитки з QR** (бібліотека `qrcode`, рендер локально в data-URL), статус-пілюлі.
- `/organizer`, `/organizer/new`, `/organizer/[id]/edit`, `/organizer/[id]` — **повний CRUD** (EventForm з
  постер-аплоадом, hide/stop-sales/cancel) + відвідувачі з CSV. Перенесено з admin/.

### admin/ (обрізано до платформи)
- Видалено `/organizer/*` і EventForm. Нав = лише Дашборд/Користувачі/Події/Замовлення/Платіжки.
- Shell виганяє не-ADMIN на /login. home→/dashboard, login→/dashboard.
